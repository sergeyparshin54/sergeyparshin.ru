# Аудит sergeyparshin.ru — 2026-11-12

## Что было и что планировалось

Одностраничная контактная визитка на GitHub Pages: `index.html`, favicon, CNAME. CRT-терминал с бесконечной ASCII-анимацией и 11 контактными ссылками. Других экранов, backend, сборки и тестов не было. Цель — быстро дать посетителю рабочие способы связи, а не усложнять сайт приложением.

## Подтверждённые проблемы и исправления

- Бесконечная анимация не имела пользовательского pause/stop. Добавлены Pause motion / Resume motion, остановка JS timer и CSS-эффектов; контент остаётся видимым. `prefers-reduced-motion` сразу показывает статичную версию без лишней кнопки.
- JetBrains Mono загружался через Google Fonts, создавая внешнюю зависимость и утечку запросов. Локальные variable WOFF2 (latin + cyrillic) добавлены в `assets/fonts/`; Google URL удалены, критический latin font preload и `font-size-adjust: from-font` применены.
- Основной смысл зависел от JS. Noscript-версия теперь содержит все 11 ссылок; `<main>` и `<h1>` ровно по одному. Style noscript перенесён в head, W3C ошибок нет.
- Добавлены landmarks, navigation label, focus-visible, target sizes 44–48px, alt для CSS decoration, язык en и читаемая разметка.
- Метаданные были минимальными. Добавлены canonical, robots, author, Open Graph, Twitter summary_large_image, theme-color и JSON-LD Person с девятью sameAs. Вместо favicon 64×64 создана локальная social card `assets/share.png` 1200×630 с alt/width/height; editable source — `assets/share.svg`.
- Независимый review подтвердил variable font и соответствие 11 контактов JS/noscript; его важное замечание о маленьком OG image исправлено. Dead RU-код и пустые no-JS nav/whois удалены, `100vh` fallback добавлен.
- На 375px нет horizontal overflow; `vw`-типографика ограничена clamp, длинные строки переносятся, motion использует compositor transform.
- CI отсутствовал. `tests/validate_site.py` проверяет landmarks, 11 ссылок, metadata/JSON-LD, локальные assets и WOFF2 signatures. Workflow использует read-only permissions и SHA-pinned actions.
